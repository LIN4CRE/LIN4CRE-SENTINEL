# Support

- Setup and recovery: read `docs/WINDOWS_SETUP.md` and export the actual installation report.
- Operations and natural-language examples: see `docs/OPERATIONS.md`.
- Test coverage and known limitations: see `docs/VERIFICATION.md`.
- Security concerns: use private vulnerability reporting as described in `SECURITY.md`; do not publish sensitive details.
- Bugs and feature requests: use the GitHub issue templates and redact tokens, private programme data, evidence and earnings.

SENTINEL does not provide guaranteed bounty outcomes, guaranteed vendor rollback, or remote administration of your PC. Windows-specific setup must be verified on the target machine.

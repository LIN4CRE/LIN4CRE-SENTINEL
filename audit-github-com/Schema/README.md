# Structured data

`schema.jsonld` is a starter graph for a **future public site only**. Replace placeholder origin, confirm OS support wording, verify current release version, then inject with `<script type="application/ld+json">` on the public product page.

- No `aggregateRating`, `review`, `downloadUrl`, or fabricated awards included.
- The price description is explicit that £0 is the software charge, not the user’s total operating cost.
- Validate with Schema.org validator and Google Rich Results Test before release.
- Add FAQPage only when the same visible FAQ content is present on that page; do not mark up hidden/duplicated content.

## SENTINEL Android Companion Preview

This is a **read-only preview companion**, not a standalone Android port. It displays a summary, programme records and scope approvals from a separately configured SENTINEL read-only API.

- Requires Android 8.0+ and a privately operated HTTPS/VPN endpoint.
- Does not run tests, approve scope, change settings, perform host maintenance, restore data or submit reports.
- APK is debug-signed by CI and is not a production signing build. Future preview APKs may require uninstalling this one before update.
- Verify the adjacent SHA-256 checksum before installation.
- Setup and threat boundary: [docs/ANDROID.md](https://github.com/LIN4CRE/LIN4CRE-SENTINEL/blob/main/docs/ANDROID.md)
